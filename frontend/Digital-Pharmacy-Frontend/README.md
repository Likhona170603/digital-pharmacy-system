# PharmaFlow homepage

1. Install Node.js 18 or newer.
2. Open this folder in VS Code (File > Open Folder).
3. Open the terminal (Ctrl + `) and run:

       npm install
       npm run dev

4. The site opens at http://localhost:5173

Files you will edit most:
- src/pages/public/Homepage.jsx  (content and layout)
- src/pages/public/homepage.css  (styling)
